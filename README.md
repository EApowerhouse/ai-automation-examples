# AI Automation Examples

This repository contains simple, real-world examples of how I use AI tools and automation platforms to improve efficiency, reduce busywork, and streamline workflows as an executive assistant and operations leader.

## 🔧 Tools Featured
- Asana
- ChatGPT
- Zapier
- Airtable
- Calendly
- Google Workspace
- Midjourney
- Ocoya.ai
- Vidyo.ai

## 🧠 Example 1: Email Follow-Up Generator (ChatGPT)
**Problem:** Rewriting polite follow-up emails over and over.  
**Solution:** I created a set of prompt templates in ChatGPT to generate follow-ups with specific tones (polite, assertive, friendly) and use them across outreach tasks.

## 🔁 Example 2: Automated Task Creation (Zapier + Gmail + Asana)
**Problem:** Important client requests would get buried in email.  
**Solution:** Created a Zap that auto-creates an Asana task anytime an email has specific keywords and tags it for my team to review.

## 📅 Example 3: Booking Workflow (Calendly + Zapier + Slack)
**Problem:** Manual Slack updates after someone booked time.  
**Solution:** When someone schedules via Calendly, a Zap sends a custom Slack message summarizing who booked and when.
