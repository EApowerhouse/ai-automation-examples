# AI Automation Examples

This repository contains simple, real-world examples of how I use AI tools and automation platforms to improve efficiency, reduce busywork, and streamline workflows as an executive assistant and operations leader.

## 🔧 Tools Featured
- Asana
- ChatGPT
- Zapier
- Airtable
- Calendly
- Google Workspace
- Midjourney
- Ocoya.ai
- Vidyo.ai

## 🧠 Example 1: Email Follow-Up Generator (ChatGPT)
**Problem:** Rewriting polite follow-up emails over and over.  
**Solution:** I created a set of prompt templates in ChatGPT to generate follow-ups with specific tones (polite, assertive, friendly) and use them across outreach tasks.

## 🔁 Example 2: Automated Task Creation (Zapier + Gmail + Asana)
**Problem:** Important client requests would get buried in email.  
**Solution:** Created a Zap that auto-creates an Asana task anytime an email has specific keywords and tags it for my team to review.

## 📅 Example 3: Booking Workflow (Calendly + Zapier + Slack)
**Problem:** Manual Slack updates after someone booked time.  
**Solution:** When someone schedules via Calendly, a Zap sends a custom Slack message summarizing who booked and when.

## ✅ Example 4: Streamlined Project Intake (Google Form + Zapier + Asana)
**Problem:** Team leads would send project requests by email or Slack, making it hard to track priorities and deadlines.

**Solution:** Created a Google Form for project intake. Responses are sent to a Google Sheet, then Zapier adds the project as a task in Asana with tags, due dates, and assignees — all automatically.

**Impact:** Reduced manual entry, ensured nothing slipped through the cracks, and gave visibility across the team’s backlog.

## 📂 Example 5: Auto-Save Client Files (Gmail + Dropbox + Slack)
**Problem:** Important client attachments needed to be archived and shared without delay.

**Solution:** Used Zapier to auto-download email attachments from starred Gmail messages, save them to Dropbox in client-named folders, and post a confirmation with the link in Slack.

**Why It Works:** It's not about Dropbox itself, it's about using cloud storage as a structured endpoint in a larger workflow.
